## 🎯 Featured Projects

### 🖥️ Hacker OS Portfolio
**Status**: ✅ Completed

A fully interactive, web-based operating system UI built with Vanilla JS and CSS. Features a functional terminal, window management system, theme toggling, and easter eggs.

**Live Demo**: [harshith-os.html](./harshith-os.html)

**Features**:
- ✨ Realistic OS simulation with boot sequence
- 🎨 Multiple color themes (Red, Green, Blue)
- 🖱️ Draggable windows with minimize/maximize/close
- 💻 Interactive terminal with command history
- 🎯 Easter eggs (Konami code: ⬆️⬆️⬇️⇩⬅️➡️⬅️➡️BA)
- 📱 Mobile responsive design
- 🌧️ Matrix rain background effect & scanlines

**Commands Available**:
```bash
help              # Show available commands
open [window]     # Open specific window
close [window]    # Close specific window
theme [color]     # Switch theme (red/green/blue)
hack [target]     # Run hacking simulation
cat roadmap.txt   # View project roadmap
whoami            # Display user info
ls                # List files
clear             # Clear terminal
reboot            # Restart system
```
